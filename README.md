# Abujana Builds — Web Development Portfolio

Responsive personal portfolio for Abujana Emmanuel, featuring a short introduction, development skills, selected project, and GitHub links. The public site is plain HTML and CSS, so it does not need a server runtime or database.

## Preview locally

Open `public/index.html` in a browser.

## Deploy on Render

Create a Git repository for this folder, push it to GitHub, then create a new **Static Site** in Render using that repository. Set the publish directory to `public`; no build command is needed. The included `render.yaml` can also be used as a Render Blueprint.
